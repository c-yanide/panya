# Panya landing page

Upload everything in this folder to the root of your GitHub repository, then turn on GitHub Pages (Settings → Pages → Deploy from a branch → main, root).

## Before you launch

1. **Waitlist.** Create a form at formspree.io. In `index.html`, replace `YOUR_FORM_ID` in both `<form>` tags with your form ID.
2. **Privacy page.** In `privacy.html`, replace `[YOUR CONTACT EMAIL]` and review the wording, including with your program if sign-ups may become research participants.
3. **Visit counts (optional).** Create a free GoatCounter account, then uncomment the GoatCounter line at the bottom of `index.html` and replace `YOUR_CODE`.

## What's here

- `index.html`: the storybook landing page
- `privacy.html`: how waitlist data is handled
- `favicon.svg`, `apple-touch-icon.png`: browser tab and home-screen icons
- `fonts/`: self-hosted, trimmed font files, with their open-source licenses in `fonts/licenses/`
